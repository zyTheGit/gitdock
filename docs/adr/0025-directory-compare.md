# ADR 0025：目录级外部对比

- 状态：已接受（2026-11-13 实现）
- 日期：2026-11-13
- 影响范围：`git-read`（`read/export.rs`、`TreeSink`、`TreeExport`）、`src-tauri`（`app/dir_diff.rs`、`app/external.rs`、`commands/read.rs`）、前端 `src/shared/ipc.ts`、`CompareView` / `CompareHeader`、i18n（compare / shell / errors / settings）
- 触发依据：需求文档第 2 节决策 10、P1「目录级对比」；用户核心痛点为「多分支代码对比」

## 1. 背景

对比视图已提供三点/两点文件级 diff 与单文件外部工具对比。用户原始痛点是同时对比两三个分支的整体代码，需要把两侧完整目录交给 Beyond Compare 这类工具，而不是逐个文件打开。

需求文档决策 10 记录的方向是「`git archive` 导出两版本到临时目录，不使用 worktree」。实现前发现两条已落地的硬约束：

1. `git-read` 的只读静态审计（`v2_readonly.rs`）禁止该 crate 内出现子进程与文件写入；
2. 依赖方向规定 Git 对象结构知识只在 `git-read`，app 层不新增 Git 交互入口。

`git archive` 属于子进程，无论放在哪一层都会破坏其中一条。因此本 ADR 修订实现机制，保留决策 10 的目标语义（导出两版本到临时目录、不建 worktree）。

## 2. 决策

1. **入口**：对比视图头部新增「目录对比」按钮；仅当 Base / Compare 两槽齐全、对比结果已加载且已配置外部工具时可用。
2. **工具选择**：使用设置中的默认工具；未指定默认工具时用列表第一项（与单文件右键菜单的兜底一致）。
3. **导出机制**：`git-read::export_tree(oid, &mut dyn TreeSink)` 用 gix 遍历树并回调条目；不启动子进程、不写文件。app 层实现 `FsSink` 落盘到临时目录。
4. **临时目录**：沿用外部 diff 根目录（`external_tmp_dir`），每次调用新建 `<nanos>-<pid>/left|right`；外部工具退出后删除整个容器，异常残留由启动清理兜底（与单文件流程同一套清理）。
5. **模板变量**：新增 `$LEFT_DIR` / `$RIGHT_DIR`；目录对比时 `$LOCAL` / `$REMOTE` 也分别指向左/右目录，已配置的文件模板无需修改即可比较目录。变量仍必须独占一个参数，复用了唯一的替换校验。
6. **对象形态**：两侧参数是槽位解析出的 commit OID；`peel_to_tree` 同时接受 annotated tag 等可 peel 对象，SHA-256 仓库同样可用。
7. **特殊条目**：
   - 符号链接：Unix 建真实链接；Windows 普通用户建链接需额外权限，改为写入「目标路径」文本文件，对比工具仍可看到指向。
   - 子模块（gitlink）：内容不在本仓库对象库内，只建空目录占位并计入跳过数。
   - 目标平台非法文件名（Windows 的反斜杠、冒号等）：跳过并计入跳过数，不中断整次导出。
8. **边界保持**：不做增量化、不跟随子模块、不处理超长路径、不提供目录级 ignore 过滤。

## 3. 备选方案（未采纳）

| 方案 | 不采纳原因 |
|---|---|
| `git archive` 放 `git-read` | 违反该 crate 的只读静态审计（禁止子进程/写文件） |
| `git archive` 放 app 层 | 把 Git 树格式知识移出 `git-read`，破坏「Git 知识各归一处」 |
| 引入 tar/zip 解压依赖 | 新增依赖与许可证门禁成本，收益仅是省掉几十行遍历代码 |
| `git worktree` 导出 | 会在仓库写元数据，决策 10 已明确排除 |

## 4. 后果

- 导出成本与仓库工作树同量级：大仓库首次导出可能耗时数秒、占用同等磁盘；工具退出前临时目录保留。
- `git-read` 的 interface 增加 `export_tree` 与 `TreeSink`，并纳入只读静态审计清单。
- Windows 上符号链接以文本占位呈现，需在验收时知晓该差异。
- 外部工具模板提示需要补充目录变量说明，设置页新增一行提示。

## 5. 验收

1. 两槽位齐全、已配置工具：头部「目录对比」可用，点击后外部工具打开两侧目录。
2. 两侧目录各自包含该提交的完整树（新增/删除文件、嵌套目录一致）。
3. 工具退出后临时目录被删除；强制结束工具时下次启动清理残留。
4. 未配置外部工具时按钮禁用并给出提示。
5. `npm run check` 全绿；GUI 实机验收按清单 9.7。
