### 0.1 四种状态不得混用

| 状态词 | 判定标准 |
|---|---|
| **代码已实现** | 当前代码与契约已落地；可引用实现提交、ADR 或自动化测试 |
| **CI 通过** | 远端 CI 对明确 commit/run 全绿；本地 `npm run check` 不叫 CI |
| **release 实测通过** | release 模式 exe + WebView2 CDP 完成指定场景；只覆盖记录中的操作，不等于安装包用户验收 |
| **用户实机验收通过** | 用户在目标机器、真实输入/外设与完整流程中确认，并留下可追溯记录 |

本清单基线中，`9b1e371` 只有本地门禁与 2026-11-26 release 模式 exe 证据，**没有绑定的当前 commit 远端 CI run**；`v0.2.8` 发布产物也不能自动覆盖 `9b1e371`。因此下列各项的 CI 状态统一记为「未绑定」，不虚构 CI 通过。
