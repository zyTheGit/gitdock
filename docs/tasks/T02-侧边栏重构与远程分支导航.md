# T02：侧边栏重构与远程分支导航

- **波次**：Wave 1（体验优化）
- **优先级**：P0
- **前置依赖**：建议在 T01 后执行（避免与 `src/App.tsx` 冲突）
- **是否需要 ADR**：否（纯前端只读展示与导航交互优化，后端 `RepoStateDto.refs` 已返回全部本地分支、远程分支与标签）
- **可并行性**：可与 T03、T04、T05 并行

---

## 1. 背景与目标

当前 [RepositorySidebar.tsx](file:///C:/zy/project_other/ai-projects/git-graph/src/app/RepositorySidebar.tsx) 存在四类高频痛点：
1. 顶部「仓库信息」占用过多首屏空间，且直接把内部调试字段 `generation`（[GraphPane.tsx](file:///C:/zy/project_other/ai-projects/git-graph/src/features/graph/GraphPane.tsx) 同样暴露）与 40 位完整 OID 铺在分支列表上方。
2. `RepoStateDto.refs` 已包含 `remote_branch`（`origin/*` 等），但侧栏、图谱分支过滤下拉、[BranchCompareDialog.tsx](file:///C:/zy/project_other/ai-projects/git-graph/src/features/compare/BranchCompareDialog.tsx) 都只过滤并展示了 `local_branch`，远程分支与标签完全缺席。
3. 仓库分支/标签数量较多时无法搜索过滤，也无法按 `/` 分组折叠（如 `feature/*`、`fix/*`）。
4. 单击本地分支会直接触发 `switch_branch`（易误操作），而单击标签无任何响应，无法直接跳转到图谱中对应提交。

---

## 2. 范围（In Scope）与边界（Out of Scope）

### In Scope
1. **精简顶部仓库信息区并隐藏内部调试字样**：
   - 将侧栏顶部「仓库信息」收敛为紧凑摘要卡片（当前 HEAD 徽标 + 短 OID 可点击复制 + 异常形态标签 `bare`/`linked worktree`/`shallow`），把对象格式、引用总数收进可折叠 `<details>`；
   - 移除面向用户的 `generation` 展示（侧栏与 `GraphPane` 计数栏均移除）。
2. **侧栏三分组 + 关键词过滤 + 前缀分组折叠**：
   - 顶部增加轻量过滤输入框（实时按名称/描述过滤本地分支、远程分支与标签，支持一键清空）。
   - 分三组展示：**本地分支**、**远程分支**（按 remote 名或 `/` 前缀折叠，例如 `origin` 下再按目录折叠）、**标签**（保留最新时间优先排序）；每组可独立折叠并记忆折叠状态（`localStorage`）。
3. **理顺点击与右键交互**：
   - **本地分支**：单击 → 在图谱中定位并选中该分支 tip 提交（若当前 scope 不包含则自动切到 `all` 或该分支，或选中定位）；**双击** → 触发 `switch_branch` 切换分支；右键菜单补充「切换到此分支」置于顶部。
   - **远程分支**：单击 → 定位到对应提交；右键菜单提供「设为 Base」「设为 Compare」「与当前 HEAD 对比」「按此引用过滤图谱」。
   - **标签**：单击 → 跳转到对应提交并高亮选中（若 `commit_oid` 存在）；右键菜单补充「设为 Base」「设为 Compare」「查看对应提交」，保留既有编辑描述与本地/远程删除。
4. **对比弹窗与图谱过滤扩展到远程分支与标签**：
   - `BranchCompareDialog` 支持从**本地分支、远程分支、标签**分组选择 Base 与 Compare（带分组标题或前缀标识，避免重名歧义，按 `full_name` 区分）。
   - `GraphPane` 的引用过滤下拉同步支持远程分支与标签（后端 `GraphScope::Branch(String)` 需确认可接收完整 ref 或远程分支名，请先核查 `crates/git-read/src/read/graph.rs` 的解析逻辑，确保传入值能被 `gix` 正确解析）。

### Out of Scope
- 不在本任务新增远程分支检出写操作（归属 T08）。
- 不在本任务计算 `ahead/behind` 徽章（归属 T08）。

## 4. 关键设计约束

- 不改变 `switch_branch` 的安全边界（仅允许切换到已有本地分支，远程分支双击/右键不得直接调用 `switch_branch`）。
- 搜索过滤须对 500+ 分支/标签保持流畅（`useMemo` 缓存过滤结果，避免无意义重算）。
- 所有新增交互项须支持键盘焦点与无障碍属性（`aria-expanded`、`title` 等）。

## 6. 验收标准

- **Given** 打开含本地分支、远程分支（`origin/*`）与标签的仓库，**When** 查看侧边栏，**Then** 默认首屏无 `generation` 调试字段，三个分组清晰可见且可独立折叠。
- **Given** 在侧栏过滤框输入关键词，**When** 键入分支或标签片段，**Then** 三个分组实时过滤并展示匹配项。
- **Given** 在侧栏单击某个本地分支或标签，**When** 触发点击，**Then** 图谱定位并高亮对应提交，不误触发切换分支；双击非当前本地分支或通过右键菜单「切换」时才进入 `switch_branch` 确认流。
- **Given** 打开「对比分支…」弹窗，**When** 展开 Base / Compare 下拉，**Then** 可任选本地分支、远程分支或标签进行三点/两点对比。
- **Given** 执行 `npm run check`，**When** 校验结束，**Then** 全部门禁通过，所有触及文件 ≤ 600 行。
