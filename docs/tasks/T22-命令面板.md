# T22：命令面板

- **波次**：Wave 3（操作发现性）
- **优先级**：P2
- **前置依赖**：T21
- **是否需要 ADR**：否（消费既有操作目录）
- **可并行性**：必须在 T21 完成后实施
- **粗略成本**：3–4 人日

---

## 1. 背景与目标

在统一操作目录完成后，命令面板可以提供快速发现与执行入口，同时减少常驻工具栏继续扩张的压力。

目标：以固定快捷键 `Ctrl+Shift+P` 打开面板，搜索并执行 T21 目录中的动作，不新增第二套命令逻辑。

---

## 2. 范围与边界

### In Scope

1. 新增命令面板弹层：
   - 搜索框。
   - 动作标题、上下文和快捷键。
   - 当前可用动作列表。
   - 禁用动作的禁用原因。
2. 默认快捷键 `Ctrl+Shift+P`，macOS 显示主修饰键映射后的组合。
3. 支持：
   - ↑↓ 选择。
   - Enter 执行。
   - Esc 关闭并消费本次按键。
   - IME 组合态 Enter 不误执行。
   - 点击执行。
4. 搜索匹配标题和上下文；首版不提供模糊参数输入或自定义命令。
5. 执行后关闭面板；若动作打开对话框，由既有流程接管。
6. 在设置快捷键帮助中增加固定快捷键说明。
7. 复用 `Modal` / Esc 分层和双语文案。

### Out of Scope

- 不实现命令参数编辑器。
- 不执行任意 Git 命令或 shell。
- 不绕过 `useWriteFlow`、Gate 或 busy 检查。
- 不新增可改键动作；首版保持固定快捷键。
- 不把命令面板当作唯一入口，右键菜单和上下文按钮继续保留。
- 不增加打开 / 关闭动画。

## 4. 关键设计约束

- 面板只消费 T21 的动作目录，不得自行拼装执行函数。
- 禁用动作可以展示原因，但不可执行。
- Esc 只关闭面板，不得触发搜索关闭、对比退出或双槽清空。
- 底部面板获得焦点时，`Ctrl+Shift+P` 仍可打开全局面板；面板内 Esc 不传递给终端。
- 搜索与列表使用 combobox / listbox 语义，当前选项通过 `aria-activedescendant` 暴露。
- 不增加动画。

## 6. 验收标准

- **Given** 应用任意主视图，**When** 按 `Ctrl+Shift+P`，**Then** 命令面板打开，搜索框获得焦点。
- **Given** 输入动作名称，**When** 查看结果，**Then** 显示匹配动作、上下文和快捷键，禁用动作显示原因。
- **Given** 使用 ↑↓ 选择并按 Enter，**When** 动作执行，**Then** 调用 T21 同一回调，面板关闭，不产生重复请求。
- **Given** 中文输入法组合态按 Enter，**When** 搜索框仍在组合，**Then** 只上屏，不执行动作。
- **Given** 面板打开时按 Esc，**When** 按键处理完成，**Then** 只关闭面板，不退出当前视图或清空对比槽。
- **Given** busy / bare / 无仓库 / 中断态，**When** 查看或执行动作，**Then** 目录禁用条件继续生效。
- **Given** 执行 `npm run check`，**When** 校验结束，**Then** 全部门禁通过，触及文件满足行数限制。
