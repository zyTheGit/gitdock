# T16：CompareBar 紧凑化

- **波次**：Wave 1（首屏精简）
- **优先级**：P1
- **前置依赖**：无
- **是否需要 ADR**：否（纯展示与交互层级调整）
- **可并行性**：可与 T14、T15、T17 并行；T19 必须等待本任务
- **粗略成本**：1 人日

---

## 1. 背景与目标

Base / Compare 双槽是核心差异化，必须保持常显；但当前提示语、HEAD 和每槽工作区按钮增加了首屏噪声。

目标：保留双槽、交换、清空和第三次选择替换提示，压缩为稳定的一行，并让低频工作区选择进入槽位更多菜单。

---

## 2. 范围与边界

### In Scope

1. 保持 `CompareBar` 在图谱模式常显。
2. Base / Compare 槽位名称、短 OID、空态、清空和交换按钮保留。
3. 每槽“工作区”选择收进更多菜单；两侧不能同时为工作区的约束不变。
4. 常驻操作提示压缩为短句或仅在空态显示；HEAD 不再占据独立常驻文本，收进标题 / 提示。
5. 长分支名使用省略与完整 `title`，不挤压交换和清空按钮。
6. 第三次 Ctrl 选择弹出的“替换哪一侧”模态保持不变。
7. 窄窗口下允许隐藏非核心 hint / HEAD，但不得隐藏两个槽位和清空入口。

### Out of Scope

- 不隐藏 CompareBar。
- 不把双槽合并为单一输入框。
- 不改变 Ctrl 选择、Esc 取消 pending、清空双槽和切换标签快照逻辑。
- 不改变三点 / 两点 / 工作区对比语义。
- 不实现常用对比方案（归属 T19）。

## 4. 关键设计约束

- 双槽是高频核心，不能收进二级菜单。
- 一行布局不得依赖固定像素宽度硬编码；使用 flex / grid 和最小宽度约束。
- 所有省略文本必须可通过 `title` 或可访问名称获取完整值。
- 菜单支持键盘和焦点返回。
- 不增加动画，不改变现有 Modal  Esc 消费协议。

---

## 5. 实施步骤

1. 盘点 CompareBar 中必须常显与可降级的信息。
2. 将槽位工作区按钮迁入更多菜单。
3. 重排槽位、交换、清空、提示和 HEAD 的视觉层级。
4. 补充窄窗口样式和完整文本提示。
5. 验证 pending 替换、工作区互斥、标签切换与 Esc。

## 6. 验收标准

- **Given** 图谱模式且未选择 Compare，**When** 查看主区，**Then** Base / Compare 两个槽位仍直接可见，空态和操作提示清晰。
- **Given** 两侧均已选择，**When** 查看 CompareBar，**Then** 名称、短 OID、交换和清空可用，常驻信息不超过一行且无横向滚动。
- **Given** 打开任一槽位更多菜单，**When** 选择工作区，**Then** 该槽切换为工作区；另一槽已是工作区时菜单项禁用。
- **Given** 两侧已选择后第三次 Ctrl 选择新提交，**When** 替换弹窗出现，**Then** 仍可选择替换 Base / Compare 或取消，Esc 行为不变。
- **Given** 窗口宽度为 640px 或更高缩放，**When** 查看 CompareBar，**Then** 两个槽位和清空入口不丢失，长名称不撑破布局。
- **Given** 执行 `npm run check`，**When** 校验结束，**Then** 全部门禁通过，触及文件满足行数限制。
