---

## 1. 背景与目标

当前图谱整行 hover 即弹出包含作者、时间、父提交、所有分支 gap 明细的大卡片，非常遮挡视线。用户期望参考 VSCode Git Graph 插件体验：**仅鼠标移到提交节点圆点上才弹出，且卡片内容极简**。

目标：将悬浮卡触发区域收敛到 Graph 列的提交圆点，并重绘为极简三段式卡片（泳道色边框 + HEAD 包含状态 + 本地/远程合并分支胶囊）。

---

## 2. 范围与边界

### In Scope

1. **节点热区与事件委托收敛**：
   - 在 `GraphCell.tsx` 中，于提交圆点 `<circle>` 上叠加一个透明命中热区 `<circle r={9} fill="transparent" data-graph-node="" data-lane={layout.lane} />`（保持 `pointer-events` 可命中，且不破坏 `GraphRow` 的 `memo` 性能）。
   - 在 `GraphList.tsx` 中，将 `onMouseOver` / `onMouseMove` 委托触发条件从 `closest("[data-oid]")` 收敛为 `closest("[data-graph-node]")`；移出节点热区立即调用 `cancelHover()`。
   - 在 `useCommitHover.ts` 中，将查询改为 `ipc.commitBranchContext(commit.oid, 0)`，同时记录当前节点的 `lane`（用于卡片边框配色）。
2. **极简三段式卡片重绘（`CommitHoverCard.tsx`）**：
   - **边框呼应**：卡片边框使用对应节点泳道色 `laneColor(lane)`。
   - **标题行**：`Commit <short_oid>`。
   - **HEAD 包含状态行**：
     - `included_in_head === true`：`已包含在 [HEAD]`（或当前分支名胶囊）。
     - `included_in_head === false`：`未包含在 [HEAD]`（或当前分支名胶囊）。
   - **所属分支行**：`Branches:` + 紧凑分支胶囊列表：
     - 抽取纯函数合并本地与远程同名分支：若本地有 `develop` 且远程有 `origin/develop`，合并展示为一枚分段胶囊 `[ develop | origin ]`（若存在多个同名远端如 `origin` / `upstream`，依次附在右侧分段）；仅远程存在时展示 `[ origin/fix/xxx ]`。
     - 最多展示 `8` 枚胶囊，超出以 `+N` 胶囊收尾。
     - 加载中显示单行轻提示，不抖动跳高。
   - **移除冗余内容**：不再展示作者/邮箱、提交与创作时间、父提交 hash、分支 gap 明细列表与底部长操作提示。
3. 同步更新中英文 i18n 文案与 `src/styles/graph.css` 样式。

### Out of Scope

- 不修改点击选中行后展示的右侧提交详情面板。
- 不实现图谱内对比区间着色（归属二期）。

## 4. 关键设计约束

- 严禁在 `GraphRow` 上新增随 hover 变化的 props，确保虚拟列表滚动与悬停时不触发全行重渲染。
- SVG 热区仅作用于提交节点圆点，连线（`<line>` / `<path>`）不触发悬浮卡。
- 卡片位置需基于视口边界夹取，不超出窗口右侧与底部，且自身 `pointer-events: none` 不阻挡鼠标移动。
- 颜色全部走 `tokens.css` 语义令牌及 `laneColor(lane)`。

## 6. 验收标准

- **Given** 鼠标在提交标题、作者、日期、hash 列移动或停留，**When** 超过 500ms，**Then** 不弹出悬浮卡。
- **Given** 鼠标移入 Graph 列的提交圆点节点，**When** 停留约 220ms，**Then** 弹出极简悬浮卡，边框颜色与该节点泳道色一致。
- **Given** 某提交同时被本地 `develop` 和远程 `origin/develop` 包含，**When** 查看悬浮卡，**Then** 合并展示为 `develop | origin` 分段胶囊，不出现重复胶囊。
- **Given** 鼠标移出节点圆点、点击提交或滚动画布，**When** 交互发生，**Then** 悬浮卡立即关闭无残留。
- **Given** 执行 `npm run check`，**When** 校验结束，**Then** 全部门禁通过，所有触及文件 <= 600 行。
