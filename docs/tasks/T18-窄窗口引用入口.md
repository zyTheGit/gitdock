# T18：窄窗口引用入口

- **波次**：Wave 2（核心工作流补强）
- **优先级**：P1
- **前置依赖**：T14
- **是否需要 ADR**：否（纯前端响应式入口）
- **可并行性**：依赖 T14 完成后，可与 T19、T20 并行
- **粗略成本**：1–2 人日

---

## 1. 背景与目标

当前可视宽度不超过 640px 时侧栏直接隐藏，没有抽屉或浮动入口，用户无法访问本地分支、远程分支和标签。

目标：增加明确的“引用”入口，在窄窗口即时展开可关闭的侧栏浮层，复用现有 `RepositorySidebar`，不引入动画。

---

## 2. 范围与边界

### In Scope

1. 顶栏增加“引用”按钮：
   - 宽窗口可用于显示 / 隐藏现有侧栏。
   - 窄窗口用于打开引用浮层。
2. 窄窗口浮层：
   - 位于顶栏与仓库标签栏下方。
   - 宽度不超过 `min(280px, calc(100vw - 16px))`。
   - 复用现有筛选、分支、远程分支、标签和 Worktree 内容。
   - 提供关闭按钮。
   - 点击外部关闭。
   - Esc 关闭且不连带退出当前视图。
3. 打开后聚焦引用过滤框；关闭后焦点返回“引用”按钮。
4. 使用 `aria-expanded`、`aria-controls` 和可读名称。
5. 窗口从窄变宽时关闭浮层并恢复普通侧栏布局，不残留遮罩。

### Out of Scope

- 不修改引用数据、分支切换、对比或 Worktree 逻辑。
- 不新增第二套引用菜单。
- 不增加侧栏展开 / 收起动画。
- 不改变 `useGlobalEsc` 的既有优先级；更内层 Modal 仍优先消费 Esc。
- 不把浮层做成阻断式模态对话框。

## 4. 关键设计约束

- 浮层内容必须复用现有侧栏，不得复制分支 / 标签渲染逻辑。
- 点击分支跳转后关闭浮层，保留图谱定位与选中结果。
- 点击外部关闭前需判断点击是否发生在浮层或触发按钮内部。
- 浮层打开时，底部面板内的 Esc 仍归底部面板内容。
- 高缩放下不得出现横向滚动或遮挡全部图谱区域。
- 不增加动画。

## 5. 实施步骤

1. 在 T14 完成后的顶栏结构中增加“引用”按钮和状态回调。
2. 实现窄窗口检测与浮层开关状态。
3. 用现有 `RepositorySidebar` 组装浮层，限制宽度和高度。
4. 接入点击外部、Esc、焦点返回和跳转后关闭。
5. 补齐样式、双语文案和无障碍属性。
6. 验证 640px 边界、窗口缩放、高缩放和键盘路径。

## 6. 验收标准

- **Given** 窗口可视宽度不超过 640px，**When** 查看主界面，**Then** 顶栏存在可识别的“引用”按钮。
- **Given** 点击“引用”，**When** 浮层打开，**Then** 可搜索并访问本地分支、远程分支和标签，焦点位于过滤框。
- **Given** 点击某分支，**When** 跳转完成，**Then** 浮层关闭，图谱定位到目标提交。
- **Given** 浮层打开，**When** 点击外部或按 Esc，**Then** 只关闭浮层，不退出搜索、对比或暂存区。
- **Given** 底部面板正在接收键盘输入，**When** 按 Esc，**Then** 不关闭引用浮层。
- **Given** 从窄窗口拖宽到普通布局，**When** 跨越 640px 边界，**Then** 浮层关闭，普通侧栏恢复且无残留遮罩。
- **Given** 执行 `npm run check`，**When** 校验结束，**Then** 全部门禁通过，触及文件满足行数限制。
