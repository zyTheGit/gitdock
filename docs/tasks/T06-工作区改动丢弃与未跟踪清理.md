# T06：工作区改动丢弃与未跟踪文件清理

- **波次**：Wave 2（P0 核心 Git 能力闭环）
- **优先级**：P0
- **前置依赖**：T01（完成 `dto.rs` 与 `App.tsx` 拆分）
- **是否需要 ADR**：**是**（新增 `WriteKind` 白名单项与破坏性写操作，须先新增 `docs/adr/0026-discard-changes.md` 并同步 `docs/03-技术架构.md`）
- **可并行性**：涉及 `git-core` 与 `git-write`，与 T07–T09 串行合并

---

## 1. 背景与目标

当前暂存区支持 `stage_files`、`unstage_files`、`create_commit` 与手动 `stash`，但缺少日常最高频的**丢弃未暂存修改**（`git restore --worktree`）与**删除指定未跟踪文件**能力，用户每次想回退临时改动都必须打开终端手动敲命令。

由于丢弃未暂存修改属于**不可通过 Git reflog 恢复的永久性数据销毁**，本任务必须严格纳入 `GitWriteModule` 白名单 + Gate 校验 + 破坏性二次确认。

---

## 2. 范围（In Scope）与边界（Out of Scope）

### In Scope
1. **契约与白名单（`git-core` + `src/shared/types.ts`）**：
   - `WriteKind` 新增 `DiscardFiles`（`discard_files`，丢弃已跟踪文件的未暂存改动）与 `RemoveUntracked`（`remove_untracked`，删除指定的未跟踪文件，或统一为 `DiscardFiles` 并在后端按 `status_detail()` 严格区分 tracked vs untracked 路径，具体设计写入 ADR-0026）。
2. **Gate 校验（新建 `crates/git-write/src/discard/` 模块，不膨胀 `gate.rs`）**：
   - 通用前置拒绝：bare 仓库、中断态、冲突索引（冲突文件严禁丢弃，必须走冲突解决或中止流程）。
   - `paths` 非空；每个路径必须存在于当前 `git status` 的未暂存列表（tracked worktree dirty 或 untracked）；拒绝路径穿越（`..`）、绝对路径与选项注入（`-` 开头由 `--pathspec-from-file=- --pathspec-file-nul` 天然免疫，但仍需校验）。
   - 返回 `affected_paths` 与 `affected_total` 供前端确认框清晰列出受影响文件。
3. **命令执行（参数数组 + NUL pathspec）**：
   - 已跟踪未暂存文件：`git restore --worktree --pathspec-from-file=- --pathspec-file-nul`（从 index 恢复工作区，不破坏已暂存内容）。
   - 未跟踪文件：`git clean -f --pathspec-from-file=- --pathspec-file-nul` 或安全校验后的受限路径删除（**绝不执行无路径参数的全局 `git clean -fd`**，且严禁清理 `.git` 或 ignored 文件）。
4. **前端入口与强破坏性确认框**：
   - `StagingView` 未暂存文件区：支持对勾选文件执行「丢弃选中改动…」，以及单行操作/右键菜单执行「丢弃改动…」。
   - 确认对话框必须明确标示为**破坏性操作（红色危险按钮）**，展示将被销毁的文件清单，并明确提示：**「工作区未暂存改动/未跟踪文件将被永久删除，无法通过 `git reflog` 恢复；如需保留请先使用 Stash」**，并提供快捷跳转 Stash 的引导。
   - 成功后通过既有 `onMutated` + `RefreshCoordinator` 刷新工作区状态、暂存区与图谱。

### Out of Scope
- 禁止支持一键「丢弃整个仓库所有改动」且跳过文件列表预览。
- 禁止支持丢弃已暂存（staged）改动（用户应先取消暂存再丢弃，避免误删）。
- 禁止删除 `.gitignore` 忽略的文件（不开放 `git clean -x`）。

## 4. 验收标准

- **Given** 某文件同时存在已暂存修改与新的未暂存修改，**When** 对该文件执行丢弃改动并确认，**Then** 仅未暂存改动回退到 index 状态，已暂存修改完整保留。
- **Given** 存在未跟踪文件（含空格与中文文件名），**When** 勾选该文件执行丢弃并确认，**Then** 仅该文件被移除，其他未跟踪文件与忽略文件毫发无损。
- **Given** 仓库处于 merge/cherry-pick 冲突态，或请求路径不在当前 `git status` 未暂存列表中，**When** 调用 `validateWrite` / `executeWrite`，**Then** Gate 明确拒绝且工作区零改动。
- **Given** 执行 `npm run check`，**When** 全部校验结束，**Then** 全部门禁与新增集成测试通过，所有触及文件 ≤ 600 行。
