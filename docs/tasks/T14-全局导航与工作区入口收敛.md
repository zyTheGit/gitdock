# T14：全局导航与工作区入口收敛

- **波次**：Wave 1（首屏精简）
- **优先级**：P0
- **前置依赖**：无
- **是否需要 ADR**：否（纯前端导航与入口调整）
- **可并行性**：可与 T15、T16、T17 并行；T18 必须等待本任务
- **粗略成本**：1.5–2.5 人日

---

## 1. 背景与目标

顶栏仓库切换器与仓库标签栏同时承担当前仓库展示、仓库切换和打开入口；工作区徽标与“暂存区”按钮执行完全相同的切换动作。

目标：

- 仓库标签栏成为唯一常驻仓库导航。
- 最近仓库、搜索、移除和打开本地仓库收进统一“打开仓库”弹层。
- 工作区徽标保留状态展示和暂存区入口，删除重复暂存按钮。
- 不改变搜索关闭、Esc、设置入口和多仓库状态语义。

---

## 2. 范围与边界

### In Scope

1. 在 `TopBar` 左侧恢复常驻 `RepositorySwitcher`：显示当前仓库名，点击下拉选择已打开/最近仓库并新增仓库。
2. 保留统一“打开仓库”弹层与本地目录选择能力：
   - 当前仓库项。
   - 最近仓库搜索与键盘选择。
   - 移除最近仓库展示项。
   - 打开本地仓库。
3. `RepoTabBar` 移除右侧“+”，保留标签切换、关闭、脏点和滚动；欢迎页继续共用同一打开弹层。
4. 删除顶栏独立“暂存区”按钮，保留 `WorkspaceBadge` 的点击切换和 `aria-pressed`。
5. 顶栏保留搜索、对比、刷新、设置；设置不移动到 Windows/Linux 原生菜单。
6. 清理仅属于被删除入口的样式和 i18n 文案。

### Out of Scope

- 不改变最近仓库的数据结构、持久化格式和“不删除磁盘仓库”的语义。
- 不改变仓库标签的打开、关闭、激活、脏点和滚动行为。
- 不改变 `closeSearch` 的“关闭即清空”行为。
- 不改变 `useGlobalEsc` 的分层优先级。
- 不新增终端顶栏入口。

## 4. 关键设计约束

- 左侧仓库下拉与标签栏可共存，但打开/新增入口不重复：标签栏不显示“+”。
- 打开弹层必须支持键盘打开、↑↓ 选择、Enter 确认、Esc 关闭和 IME 组合态。
- 工作区徽标在 bare 仓库保持禁用，只展示状态。
- 所有图标按钮必须有 `aria-label` 或可读名称。
- 不增加弹层过渡动画。
- 不把最近仓库搜索误触发为打开本地目录选择器。

## 5. 实施步骤

1. 确认 `RepositorySwitcher` 的键盘与最近仓库行为，并接入多仓库标签控制器。
2. 将左侧下拉的最近仓库打开、标签激活与新增仓库分别接入现有会话/动作入口。
3. 从 `RepoTabBar` 删除“+”，保留标签切换与关闭；顶栏删除独立暂存按钮。
4. 调整 `AppShell` 装配，保证打开弹层只有一个实例和统一关闭路径。
5. 更新样式和双语文案。
6. 运行构建、全量检查和 release GUI 回归。

## 6. 验收标准

- **Given** 已打开多个仓库标签，**When** 查看顶栏与标签栏，**Then** 顶栏左侧显示当前仓库名并可下拉切换/新增，标签栏不再显示打开仓库“+”。
- **Given** 点击左侧仓库下拉，**When** 弹层打开，**Then** 可搜索最近仓库、移除展示项、选择本地仓库；欢迎页打开的是同一弹层。
- **Given** 弹层打开，**When** 使用 ↑↓ / Enter / Esc，**Then** 键盘行为与仓库切换器一致，中文输入法组合态不会误提交。
- **Given** 非 bare 仓库，**When** 点击工作区徽标，**Then** 进入暂存区；再次点击返回图谱，顶栏没有第二个执行相同动作的按钮。
- **Given** bare 仓库，**When** 查看工作区徽标，**Then** 徽标禁用且状态可读。
- **Given** 搜索框打开后关闭，**When** 再次打开，**Then** 输入和结果仍为空。
- **Given** 执行 `npm run check`，**When** 校验结束，**Then** 全部门禁通过，触及文件满足行数限制。
