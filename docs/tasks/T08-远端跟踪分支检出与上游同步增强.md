# T08：远端跟踪分支检出、上游计数与 Push/Tag 同步增强

- **波次**：Wave 2（P0 核心 Git 能力闭环）
- **优先级**：P0
- **前置依赖**：T01、T02（侧栏已展示远程分支分组）
- **是否需要 ADR**：**是**（扩展 `RefDto` 上游计数与新增 4 个远程相关 `WriteKind`，须新增 `docs/adr/0028-remote-tracking-sync.md`；若本次一并引入带确认框的 `pull --rebase`，须同步修订 `ADR-0011`）
- **可并行性**：与 T06/T07/T09 串行合并

---

## 1. 背景与目标

当前远程能力存在 5 个高频痛点：
1. 侧栏本地分支看不到相对上游分支的 `↑ahead ↓behind` 提交数，无法直观判断需不需要 pull 或 push。
2. 新建本地分支后点击 Push，会被 Gate 直接拒绝「当前分支没有上游分支，请先在终端设置 upstream」，无法在界面内完成首次 `git push -u origin <branch>`。
3. 看到远程分支 `origin/feat-x` 时，无法右键一键检出为跟踪该远程分支的本地分支。
4. 本地创建标签后，能删远程标签却**不能推送标签到远程**；且远程分支删除后缺少 `git fetch --prune` 清理本地失效远程跟踪引用。

---

## 2. 范围（In Scope）与边界（Out of Scope）

### In Scope
1. **只读上游状态感知（`git-core` + `git-read`）**：
   - `RefDto`（或专用可选字段）补充本地分支的 `upstream?: string`、`ahead?: u32`、`behind?: u32`；
   - `git-read` 纯 `gix` 计算本地分支与其配置上游（`branch.<name>.remote` + `branch.<name>.merge`）的 ahead/behind（注意大仓库性能控制：只算本地分支，并设置合理步数上限或复用图遍历，避免拖慢 `open_repository`）。
   - 侧栏本地分支项右侧展示紧凑徽章（如 `↑2` / `↓1`）。
2. **新增远程白名单写操作（`git-write`）**：
   - `CheckoutRemoteBranch`：`git switch -c <local_name> --track <remote_ref>`（Gate：目标本地分支不存在、合法分支名、远程跟踪引用存在、dirty 语义对齐 ADR-0002）。
   - `PushSetUpstream`：`git push -u <remote> <branch>`（Gate：当前在本地分支且无上游、存在至少一个 remote、非 unborn/detached；默认 `origin` 或唯一配置的 remote，在确认框明确展示目标 remote 与分支名）。
   - `FetchPrune`：`git fetch --prune`（Gate 同 `Fetch`；在图谱 Fetch 按钮旁或下拉提供「Fetch 并清理失效远程分支」）。
   - `PushTag`：`git push origin refs/tags/<tag>`（Gate：本地标签存在、存在 remote；标签右键菜单新增「推送标签到远程…」，执行前确认）。
3. **前端交互衔接**：
   - 当用户点击 Push 而当前分支无上游时，不再只报死错误，而是弹出提示确认「为当前分支设置上游 `origin/<branch>` 并推送？」（触发 `PushSetUpstream`）。
   - 侧栏远程分支右键菜单新增「检出为本地分支…」（弹出确认/可改本地分支名）。
   - （可选，须在 ADR 决策）如引入 `pull --rebase`，必须走 `ConfirmWriteDialog` 历史改写确认 + `git rebase --abort` 恢复说明，绝不走无确认直执。

### Out of Scope
- 严禁加入 `--force` / `--force-with-lease` 推送。
- 严禁记录或弹窗询问用户 Git 密码/Token（坚持系统凭据管理器与 SSH agent 策略）。
- 暂不做多 remote 管理增删改界面（多 remote 场景可在后续单独规划）。

## 4. 验收标准

- **Given** 本地分支领先上游 2 个提交、落后 1 个提交，**When** 打开仓库或刷新，**Then** 侧栏该分支显示 `↑2 ↓1` 计数，且不显著拖慢大仓库打开耗时。
- **Given** 存在远程分支 `origin/feat-a` 且本地无同名分支，**When** 右键「检出为本地分支…」并确认，**Then** 创建并切换到 `feat-a`，其上游指向 `origin/feat-a`。
- **Given** 新建本地分支尚无上游，**When** 点击 Push 并确认设置上游推送，**Then** 推送成功且分支自动建立 `origin/<branch>` 跟踪关系。
- **Given** 本地存在新建标签 `v1.0.0`，**When** 右键「推送标签到远程…」并确认，**Then** 远端仓库出现 `refs/tags/v1.0.0`；执行「Fetch 并清理」后，远端已删除分支的本地 `origin/*` 引用被清理。
- **Given** 执行 `npm run check`，**When** 校验结束，**Then** 全部门禁与新增测试通过，所有触及文件 ≤ 600 行。
