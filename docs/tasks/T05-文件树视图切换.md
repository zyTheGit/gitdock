# T05：通用文件树视图切换（提交详情 / 对比 / 暂存区）

- **波次**：Wave 1（体验优化）
- **优先级**：P0
- **前置依赖**：无
- **是否需要 ADR**：否（纯前端展示层能力）
- **可并行性**：可与 T01、T02、T03、T04 并行（纯新增通用组件 + 轻量接入三处文件列表）

---

## 1. 背景与目标

目前提交详情（`CommitDetailPane`）、双槽对比（`CompareFileList`）、放大 Diff 侧栏（`FileDiffView`）以及暂存区（`StagingFileList`）全部采用扁平文件路径列表。当一个提交或分支对比涉及数十上百个文件时，长路径难以一眼看出改动分布在哪些模块目录，也无法按目录折叠跳过无关变更（如锁文件、测试夹具目录）。

目标：构建一套高性能、支持虚拟化的通用「扁平列表 / 目录树」切换能力，统一覆盖上述 4 处文件列表视图。

---

## 2. 范围（In Scope）与边界（Out of Scope）

### In Scope
1. **纯函数目录树构造器（`src/shared/fileTree.ts`）**：
   - 将带 `path` 字段的文件数组转换为树节点，并支持**压缩单子目录**（compact folders，例如 `src/features/compare` 合并显示为一行，类似 VS Code）；
   - 按「目录优先、同层字典序」排序，支持统计每个目录节点下包含的文件总数；
   - 提供 `flattenVisibleTree(nodes, collapsedDirs)` 输出扁平行数组（`DirRow | FileRow`，携带 `depth` 缩进层级），天然适配 `@tanstack/react-virtual` 虚拟滚动！
2. **偏好持久化**：
   - `localStorage` 键 `gitdock.file-list-mode`（`"flat" | "tree"`，默认 `"flat"` 或按用户上次选择），支持跨视图同步（可用简单 `useSyncExternalStore` hook `useFileListMode()`）。
3. **接入 4 处文件列表**：
   - `src/features/detail/CommitDetailPane.tsx`：文件区标题旁增加「列表 / 目录树」切换图标按钮；
   - `src/features/compare/CompareFileList.tsx`：同样接入切换按钮；
   - `src/features/diff/FileDiffView.tsx`：放大视图左侧文件栏同步遵循 `fileListMode`；
   - `src/features/staging/StagingFileList.tsx`：暂存区未暂存/已暂存列表支持目录树展示（保留文件勾选框、状态字母、增删行数、单文件暂存/取消暂存按钮与右键菜单；目录行支持点击折叠/展开，并可选提供勾选该目录下全部文件）。

### Out of Scope
- 不修改后端任何 DTO 或排序逻辑。
- 不在本任务新增“按目录批量暂存”的后端命令（若支持目录勾选，前端直接展开该目录下所有文件路径传给既有 `stage_files`/`unstage_files` 即可）。

---

## 4. 关键设计约束

- **保持大提交性能**：必须通过 `flattenVisibleTree` + `@tanstack/react-virtual` 渲染，严禁递归渲染数千个未虚拟化的嵌套 `<ul><li>` DOM 节点。
- **文件名与重命名展示**：目录树模式下，文件行只展示 basename（如 `CompareView.tsx`），`title` 悬停展示完整路径（重命名文件展示 `old_path → path`）。
- **无障碍与主题**：目录行使用 `<button>` 并设置 `aria-expanded`，颜色全部使用 `tokens.css` 语义令牌。

---

## 5. 验收标准

- **Given** 打开含多层嵌套目录与 100+ 变更文件的提交或对比结果，**When** 点击切换到「目录树」模式，**Then** 文件按目录层级分组展示、单子目录自动合并、点击目录可平滑折叠/展开，且虚拟滚动流畅无卡顿。
- **Given** 在提交详情切换为目录树模式，**When** 切换到对比视图、放大 Diff 或暂存区，**Then** 各视图自动同步为目录树模式，重启后保持偏好。
- **Given** 暂存区处于目录树模式，**When** 单击文件行查看 diff、勾选文件或点击行内暂存/取消暂存，**Then** 所有既有功能行为完全一致。
- **Given** 执行 `npm run check`，**When** 校验完成，**Then** 全部门禁通过，所有触及文件 ≤ 600 行。
