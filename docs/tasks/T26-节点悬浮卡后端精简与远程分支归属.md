# T26：节点悬浮卡后端精简与远程分支归属

- **波次**：Wave A（底座）
- **优先级**：P1
- **前置依赖**：无
- **是否需要 ADR**：可与 T23 合并落一篇 ADR（扩展 `CommitBranchContextDto`）
- **可并行性**：可与 T23、T24、T25 并行；T27 必须等待本任务
- **粗略成本**：0.5 人日

---

## 1. 背景与目标

当前 `commit_branch_context` 只统计本地分支（`refs/heads/*`），且每次悬停都为最多多个其他分支计算完整的 `branch_gap`（包含可达集差集与缺失提交列表），既重又缺少远程分支归属信息。

目标：让 `commit_branch_context` 补齐 `included_in_head` 与 `remote_branches`，并在 `limit == 0` 时跳过昂贵的 `branch_gap` 遍历，为极简节点悬浮卡提供快而准的分支归属数据。

---

## 2. 范围与边界

### In Scope

1. 在 `crates/git-core/src/dto/compare.rs` 的 `CommitBranchContextDto` 新增字段：
   - `#[serde(default)] pub included_in_head: bool`
   - `#[serde(default)] pub remote_branches: Vec<String>`（包含该提交的远程分支短名，如 `origin/develop`）
2. 在 `crates/git-read/src/read/detail.rs` 更新 `commit_branch_context`：
   - 计算 `included_in_head`（`head_set` 是否包含 `oid`，兼容 detached HEAD）。
   - 遍历 `refs/remotes/*`（忽略符号引用如 `origin/HEAD`）计算包含 `oid` 的远程分支列表 `remote_branches`，排序规则与本地分支一致（tip 优先，其次按名称/提交时间稳定排序）。
   - 当 `limit == 0` 时直接跳过 `branch_gap` 循环（`gaps` 为空、`gaps_omitted = 0`），显著降低悬停查询耗时。
3. 同步更新 `src/shared/types.ts`。
4. 在 `crates/git-read/tests/read_refs.rs` 补充单测：
   - `included_in_head`（在 HEAD 内、不在 HEAD 内、detached HEAD）。
   - `remote_branches` 正确识别包含提交的远程分支并排除 `origin/HEAD`。
   - `limit == 0` 时跳过 `gaps` 且 `branches` / `remote_branches` / `included_in_head` 仍准确返回。

### Out of Scope

- 不删除 `gaps` / `gaps_omitted` 字段（保持 IPC 协议向后兼容）。
- 不修改前端悬浮卡组件（归属 T27）。

## 4. 关键设计约束

- 严格遵守 `git-read` 只向下依赖 `git-core` 的边界。
- 过滤远程分支时必须跳过无 `commit_oid` 或 `HEAD` 指向的冗余项，避免悬浮卡出现 `origin/HEAD` 噪音。
- 复用既有 `refs_snapshot` 与 `reachable_set`，不引入 shell 调用。

4. 运行 `cargo test -p git-core -p git-read` 验证。

## 6. 验收标准

- **Given** 某提交同时属于本地 `develop` 和远程 `origin/develop`，且在当前 HEAD 历史中，**When** 调用 `commit_branch_context(oid, 0)`，**Then** `included_in_head == true`、`branches` 含 `"develop"`、`remote_branches` 含 `"origin/develop"`、`gaps` 为空。
- **Given** 某提交仅属于远程分支 `origin/fix/a` 且不在当前 HEAD 历史中，**When** 调用 `commit_branch_context(oid, 0)`，**Then** `included_in_head == false`、`remote_branches` 含 `"origin/fix/a"`。
- **Given** detached HEAD 指向包含该提交的节点，**When** 调用 `commit_branch_context(oid, 0)`，**Then** `included_in_head == true`、`current_branch == None`。
- **Given** 执行 `cargo test -p git-read` 与 `npm run build`，**When** 校验结束，**Then** 全部通过。
