# GitDock 选型终审

> 状态：已选定开发路线；后续 Spike 只验证风险，不重新开放同类方案竞选。若触发否决条件，须新建 ADR 后再变更。

## 最终选择

| 层次 | 选择 | 原因 |
|---|---|---|
| 桌面壳 | Tauri 2 | Windows 使用 WebView2，Rust 后端可收拢文件系统与 Git 权限。 |
| 前端 | React + TypeScript | 适合虚拟列表、结构化 diff 与高频状态局部刷新。 |
| 后端 | Rust stable | Git 读取、布局和并发取消可集中在单一原生进程。 |
| 只读 Git | gix | 支持 revision walk，并具备 SHA-1 / SHA-256 对象格式能力。 |
| Git 写入 | 系统 Git CLI | 保留 hooks、filters、LFS、autocrlf 与 Git for Windows 语义。 |
| 图谱布局 | 自研纯函数模块 | 稳定 lane、跨页待连接边和 Git ref 标记是产品核心，通用节点图库不匹配。 |
| 虚拟滚动 | `@tanstack/react-virtual`（POC 准入） | headless MIT 组件，只承载已取得数据的视口渲染。 |
| diff 呈现 | `react-diff-view`（POC 准入） | MIT；用于单文件 patch 的 hunk 模型与展示。 |
| 高亮 | Shiki（POC 准入） | MIT；仅按需加载与高亮可视行。 |

## 明确排除

- 不使用 git2/libgit2 作为 MVP 主读取层：SHA-256 路径仍存在实验性风险。
- 不使用 React Flow、AntV G6、GitGraph.js 承载主 DAG：它们不能承担拓扑分页与稳定 lane。
- 不复制或依赖 VS Code Git Graph 源码、样式、图标、资源或测试夹具。
- 不复制或依赖 GitButler 源码/资源；其当前 FSL 不适合本项目。
- 不迁移 Lazygit 的 Go/TUI 代码；仅借鉴其操作与刷新分层。

## 版本与依赖规则

1. 初始依赖只允许 MIT、Apache-2.0 或经项目明确审批的许可证；锁版本时生成第三方通知。
2. Tauri 固定在 2.x 主线，Rust 使用当前 stable；gix 固定兼容 SHA-1 / SHA-256 feature 的已验证版本。
3. 前端候选组件必须经过大列表/大 diff POC 后才进入正式依赖清单；未通过则保留接口，自研实现适配器。
4. Rust 后端不向 WebView 暴露任意命令执行、任意路径读写或 Git 原始命令接口。

## 否决条件与处理

| 触发条件 | 处理 |
|---|---|
| gix 无法稳定读取 SHA-256 fixture | 将 MVP 明确收紧为拒绝 SHA-256 仓库，增加启动检测与用户提示。 |
| Tauri 在分页/大 diff 下无法满足响应预算 | 先缩小 DTO 与渲染范围；仍不通过才评估 egui，并以 ADR 替换本终审。 |
| 前端组件要求完整历史或完整 diff 常驻 | 不引入；自研相同 seam 的适配器。 |
| 系统 Git 低于最终最低版本或缺失 | 只读能力可用时提示升级；写操作与不兼容能力禁用。 |

一手资料与许可证调查见 [Spike 调研](spike-research.md) 和 [开源参考调研](oss-reference-research.md)。
